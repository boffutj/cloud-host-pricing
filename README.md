## 比价之前，先分清三种计费模式

同一台云服务器，计费方式不同，花出去的钱能差出几倍。主流厂商的计费基本都分三种：包年/包月、按需计费、竞价计费。

包年/包月是预付费，先买后用，按订单周期结算，所有“XX元一年”的活动价都属于这一类，适合官网、博客、在线商城这种长期稳定跑的业务。按需计费是后付费，按实际使用时长结算，适合电商大促、临时测试这类用完即关的短周期场景。竞价计费最特殊：按市场供需浮动定价，价格能低到按需价的零头，但库存紧张或市价超过你设的价格上限时，实例会被系统直接释放回收。

华为云还把竞价细分成“竞享模式”，价格压得更低，回收机制同样存在。竞价类实例适合图像渲染、离线分析、批量计算这类不怕中断的任务，拿去挂正式网站等于给自己埋雷。

所以看任何价格表，先确认它对应哪种计费。拿竞价实例的单价去跟包年价格比便宜，是比价内容里最常见的错位。

## 同样是2核4G，一年199元和一年1710元差在哪

差在两处：带宽形态和实例档次，这也是云主机报价单里最容易看迷糊的部分。

先说带宽。固定带宽是“保证值”——3M固定带宽意味着任何时刻最高3Mbps，稳定但上限低，下载文件大约0.4MB/s。峰值带宽是“上限值”——200M峰值表示网络空闲时最高能冲到200M，网页打开、文件传输的体验完全不同。阿里云轻量的新客款和298元的2核4G款都标注不限流量，这也是同配置下峰值带宽款更贵的原因之一：2核4G固定4M卖298元/年，200M峰值款月付70元。

再说实例档次。经济型e是入门走量款，同配置里最便宜；通用算力u1高半档；c7/c8i、g7/g8i则是企业级标准实例。数据很直白：2核4G，e实例725.64元/年，c7要1611.68元，c8i要1710.38元，差出一倍多。多花的钱买的是CPU调度、网络质量和稳定性，跑数据库、API服务、生产业务值这个价；个人博客用它属于花冤枉钱。

## 下单前的四个常见问题

**38元一年的云主机是真的吗？**
真的，但它是秒杀价：限时、限量、通常限新客。抢不到就是68元活动价，再不行还有99元续费同价兜底，38元属于“蹲到算赚到”。

**续费一般会涨多少？**
没有统一数字，涨幅取决于机型和活动。可以确定的规律是：首购价越夸张的机型，续费涨幅越大。买之前在页面找“续费价格”或“续费同价”字样，找不到就按标准价估算，别拿首购价乘以年数做预算。

**固定带宽和峰值带宽怎么选？**
以网站访问为主，选峰值带宽，体验好；需要稳定对外提供服务（API、下载、推流），固定带宽的可预期性更重要。预算敏感的话，阿里云轻量新客款200M峰值且不限流量，数值上很占便宜。

**新客资格用完了怎么办？**
一条路径是用家人朋友的身份注册新账号购买，买完再迁移到自己名下；另一条是到期换一家厂商重新享受首购价。两条路都有操作成本，懒得折腾的话，一开始就选续费同价的机型最省心。
